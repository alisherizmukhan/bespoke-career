# Bespoke — документация проекта

Bespoke — веб-сервис для поиска работы в США. В одном месте он показывает вакансии и зарплаты, помогает подготовить резюме и вести отклики, а ИИ-ассистент отвечает на вопросы по поиску работы.

Документация написана для человека, который не участвовал в разработке, но должен понимать проект целиком и защищать его перед комиссией.

**Живой сайт:** https://bespoke-career.vercel.app
**API:** https://bespoke-api-sbc7.onrender.com (проверка: `/health`)
**Репозиторий:** приватный GitHub `alisherizmukhan/bespoke-career`

## Цифры проекта

- Около 130 файлов в репозитории. Бэкенд на Python (FastAPI) — около 6 900 строк, фронтенд на TypeScript (Next.js) — около 5 000 строк.
- 118 API-эндпоинтов, 36 страниц сайта, 33 таблицы в базе данных.
- 35 автоматических тестов. Они вызывают каждый эндпоинт и проверяют безопасность и оплату.
- Около 6 000 живых вакансий из 59 источников, обновление каждый час.
